# Phase 15 — адресные секреты (первый слой)

В одиночном чате секретные записи категории `secret` доступны для автоматической, закреплённой и принудительной вставки **только если имя отвечающего персонажа точно присутствует в `knownTo`**. В групповых чатах или при неизвестном адресате такие записи не отправляются.

Это не полноценное разделение знаний: сводки сцен, общий сюжет и обычные записи других категорий могут содержать секретную информацию; их нельзя надёжно очистить без структурирования. Фильтр не определяет знания по косвенным намёкам, не делает запросов к API, не меняет архив и не расходует дополнительные токены.

Проверка: `npm test`. Реальную ролевую нужно проверять отдельно.
