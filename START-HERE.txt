НИТЬ ПАМЯТИ / MEMORY THREAD — 1.0.0-beta.3.3 · STORY JOURNAL

УСТАНОВКА

1. Замени старую папку memory-thread новой целиком.
2. Итоговый путь до манифеста:
   SillyTavern/public/scripts/extensions/third-party/memory-thread/manifest.json
3. Обнови страницу SillyTavern. Появится кнопка 🧵.

ЧТО НОВОГО В BETA.3.3

- Служебный архивный промпт теперь компактнее и на английском; память и весь читаемый результат остаются на русском.
- Проверка размера диапазона использует токен-счётчик SillyTavern, когда он доступен.
- Более понятные ошибки: слишком большой диапазон, API/ключ/баланс, JSON, обрезанный ответ и смена чата.
- Для слишком большого диапазона Memory Thread прямо пишет, что запрос не был отправлен и API не расходуется.
- В настройках есть кнопка для короткого рекомендуемого английского дополнительного промпта.
- Добавлены лёгкие блёстки/орнаменты Story Journal без тяжёлых изображений.
- Все возможности beta.3 (🔞 взрослые сцены, merge/delete, дневник и контекст) сохранены.

РЕКОМЕНДУЕМЫЙ РИТМ

Играй 10–15 содержательных сообщений → «✨ Запомнить новое» → проверь память → при желании /hide старый диапазон → продолжай. Для очень длинных сообщений бери меньше; для короткой цельной сцены можно немного больше.

Перед заменой версии можно сохранить «Экспорт памяти». Настройки и память предыдущих beta.3.x совместимы с beta.3.3; новые переключатели взрослых сцен по умолчанию выключены.
