УСТАНОВКА

1. Замени старую папку memory-thread новой целиком.
2. Итоговый путь до манифеста:
   SillyTavern/public/scripts/extensions/third-party/memory-thread/manifest.json
3. Обнови страницу SillyTavern. Появится кнопка 🧵.

ЧТО НОВОГО В BETA.3

- Новый интерфейс в стиле сюжетного дневника: более компактные вкладки, карточки, летопись сцен и визуальный «дневник истории».
- 🔞 Режим взрослых сцен для вымышленных совершеннолетних персонажей: архивариус не должен терять значимые последствия интимной сцены. Дополнительный переключатель позволяет сохранить конкретную деталь, если она реально важна для будущего сюжета. Это не обход ограничений API.
- 🔗 «Объединить» для дублей и связанных воспоминаний. Результат становится ручной защищённой записью.
- 🗑 «Удалить» для окончательного удаления всех версий выбранного ключа памяти.
- Вкладка «Контекст» прямо поясняет, что «Обновить предпросмотр» не вызывает модель и не тратит API.

РЕКОМЕНДУЕМЫЙ РИТМ

Играй 10–15 содержательных сообщений → «✨ Запомнить новое» → проверь память → при желании /hide старый диапазон → продолжай. Для очень длинных сообщений бери меньше; для короткой цельной сцены можно немного больше.

Перед заменой версии можно сохранить «Экспорт памяти». Настройки и память beta.2 совместимы с beta.3; новые переключатели по умолчанию выключены.
