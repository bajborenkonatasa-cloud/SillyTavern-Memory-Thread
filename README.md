# 🧵 Нить памяти · Memory Thread

**1.0.0-beta.1 — первая тестовая версия для SillyTavern.**

Ручная память для ролевых: сцены, даты, отношения, секреты, обещания и точные реплики. Создана для коротких и средних историй, в том числе чатов примерно до 300 сообщений. Не требует векторизации, Node-плагина или установки npm-зависимостей для обычного использования.

## Установка из этого ZIP

1. Распакуй архив. Внутри должна быть папка `memory-thread`.
2. Скопируй **эту папку целиком** в папку установленной Таверны:

   `SillyTavern/public/scripts/extensions/third-party/memory-thread/`

3. Проверь, что `manifest.json`, `index.js`, `core.js`, `api.js` и `style.css` лежат непосредственно в `memory-thread`, без второй вложенной папки с таким же именем.
4. Обнови страницу Таверны. Если расширение отключено в списке расширений, включи его. На экране появится кнопка 🧵.

**Поле «Установить расширение» в Таверне обычно принимает Git-URL, а не ZIP.** Для ZIP нужен доступ к файлам установки. Если Таверна у тебя на чужом хостинге, папку должен установить владелец сервера либо нужно будет разместить исходники в Git-репозитории. Архив не публикует репозиторий автоматически.

На Android с Termux путь зависит от места установки Таверны. Копировать нужно на устройство/сервер, где работает SillyTavern, а не просто в папку загрузок телефона, который открывает её в браузере.

## Первые пять минут

1. Открой **копию чата для проверки** и нажми 🧵.
2. Оставь «Текущее API Таверны» в настройках. Убедись, что обычные ответы модели работают.
3. Нажми «Диапазон», выбери небольшой участок из 5–10 сообщений. Нумерация как в Таверне: **№0 — первое сообщение**.
4. Просмотри оценку объёма и нажми «Отправить и сохранить». На первой проверке оставь скрытие выключенным.
5. Открой «Воспоминания», проверь факты, цитаты и даты. Посмотри «В контекст».
6. Попробуй «Править» и «Вспомнить», затем получи обычный ответ персонажа.
7. Когда результат устраивает, используй обработку со скрытием. До переноса основной истории сохрани полный экспорт чата Таверны и экспорт памяти.

## Панель

| Раздел | Содержимое |
| --- | --- |
| Сейчас | Последняя сохранённая сцена, общая сводка, пропуски обработки |
| Воспоминания | Карточки, поиск, ручное добавление и редактирование |
| История | Сводки обработанных диапазонов и исходные сообщения |
| В контекст | Текст зарегистрированного блока памяти, токены, переполнение |
| Настройки | Подключение, бюджет, промпт, экспорт и импорт |

Плавающую кнопку можно перетаскивать пальцем или мышью. Положение запоминается. Есть дополнительный пункт «Нить памяти» в меню волшебной палочки, если стандартный контейнер меню доступен в сборке Таверны.

## Основные действия

- **Запомнить новое:** находит первый необработанный участок, по умолчанию максимум 15 сообщений. Если есть старый пропуск, начнёт с него; не пропустит его ради самых новых сообщений.
- **Диапазон:** обработка любых выбранных номеров, включая скрытые. Повторная обработка допустима.
- **После сохранения скрыть:** сначала получает и проверяет JSON, сохраняет память штатным механизмом, проверяет серверную копию, затем вызывает штатную `/hide`. Если сохранение нельзя подтвердить, скрытие не начинается.
- **Своя запись / Править:** сохраняет ручную защищённую версию. ИИ не переписывает её. Ручные записи остаются и после удаления исходного сообщения — проверь их при смене сюжетной ветки.
- **Закрепить:** повышает приоритет отправки. Огромная запись всё равно не может превысить общий лимит: панель покажет, что она не вместилась.
- **Вспомнить:** добавляет запись в очередь ближайшего обычного ответа.
- **Флешбэк:** дополнительно просит модель отразить воспоминание в ответе. Это инструкция модели, не гарантия конкретной сцены.
- **Отключить:** убирает запись из контекста без удаления. Включить можно через «Отключённые».
- **Источник:** показывает исходный текст в окне; не раскрывает скрытые сообщения в запросе.
- **Показать последний скрытый нами диапазон:** вызывает `/unhide` только для сообщений, которые эта операция расширения скрыла. Сообщения, скрытые до неё, не затрагиваются.

## Автоматические плашки

Поиск использует последние четыре сообщения, ключевые слова, имена участников и совпадения слов в записях. Это **поиск по словам и связям, без embeddings/векторизации**. Поддерживается кириллица, нормализация регистра и ё/е; понимание синонимов и склонений не гарантируется.

Высокая важность, закреплённые записи, общая сводка и последняя сохранённая сцена тоже участвуют в отборе. Плашка показывает запись, реально включённую в зарегистрированный блок контекста, и причину совпадения. Повторный показ ограничен паузой, по умолчанию 8 сообщений. Плашки можно выключить, сохранив саму память.

Ручное напоминание снимается после полученного ответа, только если оно поместилось в контекст. После отменённой генерации оно остаётся. Quiet-генерации расширение не использует для расходования очереди.

## Модели и API

### Текущее API Таверны

Используется `SillyTavern.getContext().generateRaw` с отдельной инструкцией и выбранным текстом. Модель не пишет новый пост в чат, а возвращает JSON для памяти. Вызов учитывает особенности текущего подключения Таверны. Не запускай одновременно обычную ролевую генерацию и обработку памяти через то же подключение.

### Отдельное OpenAI-совместимое API

1. В настройках выбери соответствующий режим.
2. Введи базовый URL, обычно `https://provider.example/v1`.
3. Введи ключ и название модели. «Загрузить модели» читает `/models`; если провайдер не поддерживает этот маршрут, название можно ввести вручную.
4. «Проверить отдельный API» отправляет маленький реальный запрос; он может учитываться в тарифе.
5. Сохрани настройки.

Запрос идёт на `/chat/completions`, без стриминга, с `messages` и `max_tokens`. Специального JSON-режима от провайдера не требуется, но модель должна соблюдать JSON в ответе. Это не адаптер для любого API: нативные Anthropic/Gemini-протоколы напрямую не реализованы.

**CORS:** браузер должен иметь разрешение обращаться к выбранному провайдеру. Если он запрещает такие запросы, используй настроенное подключение Таверны. Расширение не отправляет ключ через сторонний обходной прокси.

Ключ хранится в `sessionStorage` текущего сайта/вкладки, не в файле памяти и не в сохраняемых настройках Таверны. После закрытия сессии может потребоваться ввод заново. Скрытое поле пароля — не шифрование от других расширений той же страницы. Экспорт памяти не содержит ключей.

## Расход токенов

- При обработке: выбранный диапазон + инструкция + действующие записи + компактный предыдущий сюжет/дополнительные сводки + ответ модели.
- При обычной ролевой: только отобранный блок памяти. По умолчанию **до 1 500 токенов** по счётчику текущей Таверны.
- Поиск и плашки сами не вызывают API.
- Перед обработкой показывается приблизительный объём входа (эвристика для смешанного русского текста). Это не точный счёт провайдера.
- Для контекстного блока используется токенизатор Таверны, а при его недоступности — приближённая оценка. Тарифные значения провайдера могут отличаться.
- Если провайдер отдельного API возвращает `usage`, оно показывается в настройках после обработки.

Лимит ответа по умолчанию — 2 400 токенов. Если JSON обрезан, увеличь лимит или уменьши диапазон. Перед отправкой действует настраиваемый лимит входа, по умолчанию оценка 14 000 токенов. Поставь значение с запасом относительно реального контекстного окна модели и лимита её ответа.

## Даты, секреты и цитаты

Даты сохраняются как текст: исторические годы и необычные календари допустимы. Автоматического вычисления возраста или количества прошедших суток нет. Неизвестная дата остаётся пустой.

В записях есть участники, круг осведомлённых и статус: факт, мнение/подозрение, сон/видение, неясное. Они помогают модели соблюдать канон; само наличие полей не гарантирует идеальной интерпретации.

Автоматическая цитата должна **дословно встречаться** в одном из указанных исходных сообщений. Неточная цитата удаляется с уведомлением. Имя говорящего извлекает модель: NPC внутри чужого сообщения может быть настоящим автором реплики. Ручные цитаты пользователь подтверждает самостоятельно.

## Защита истории

Каждое сообщение получает устойчивый ID в `extra.memoryThreadId`. Записи имеют ID источника и отпечаток его текста. При свайпе, редактировании или удалении зависимые автоматические записи исключаются из контекста. При возвращении прежнего текста соответствующая версия снова может стать действующей. Если одна реплика в обработанном диапазоне изменилась, весь этот диапазон снова считается требующим обработки.

Изменения одного факта с одинаковым ключом хранятся версиями: более поздняя по сюжету действующая запись выбирается автоматически. Качество выбора ключей зависит от модели. Ручная защищённая версия имеет приоритет. Повторный скан одинакового диапазона не создаёт дубликатов действующей сводки.

Переключение чата во время запроса отменяет применение результата. Перед фиксацией проверяется, что использованный текст и память не изменились. Для отдельного API отмена прерывает запрос; для API Таверны результат отбрасывается, но сам запрос может завершиться в фоне.

Сохранение идёт в метаданные текущего чата. Настройки общие, сами воспоминания отдельные для каждого чата. При ветвлении Таверна может скопировать ручные записи вместе с метаданными: они сохраняются намеренно. Автоматические записи без действующего источника в ветке не используются.

## Экспорт и перенос

«Экспорт памяти» скачивает JSON с записями и сводками. Полный чат экспортируется отдельно средствами Таверны.

Для переноса с автоматическими источниками сначала перенеси полный чат, сохранив его `extra` и метаданные. Затем, если нужно, восстанови JSON Memory Thread. В чужом чате без совпадающих ID автоматически извлечённые записи не активируются; ручные записи остаются активными. Перед восстановлением расширение скачивает копию прежней памяти.

Импорт Facts Memory Tracker понимает массив фактов и объекты с `facts`, `state.facts` или `data.facts`. Импортированные факты становятся ручными защищёнными записями без проверенных источников. Даты, ключевые слова и круг осведомлённых можно дополнить вручную. Исходная история при импорте не изменяется; импорт фактов не помечает диапазоны чата как обработанные.

После проверки переноса отключи **инъекцию** памяти старых расширений, чтобы одни и те же факты не отправлялись дважды. Удалять их данные не нужно.

## Проверено и пока не проверено

Реализация сверена с публичными интерфейсами ветки `release` SillyTavern на момент создания: `getContext`, `generateRaw`, `getTokenCountAsync`, `setExtensionPrompt`, `saveMetadata`, `/hide`, `/unhide`, чтение серверного чата.

- Автотесты ядра: источники, правки, ветки, скрытая история, цитаты, импорт, версии, лимит токенов.
- Интеграционные тесты в Chromium с имитацией API Таверны: интерфейс, обработка и скрытие, ручные правки, флешбэк, мобильная ширина, ошибка модели, отказ сохранения, смена чата, безопасный вывод текста.
- **Не выполнена проверка с живым провайдером и твоей конкретной сборкой Таверны.** Поэтому версия обозначена beta. Групповые пути сохранения предусмотрены по API, но основной интеграционный сценарий — одиночный чат.
- Векторизация, сложный календарный движок, RPG-показатели и автоматическая обработка по таймеру не включены. Обработка ручная, напоминания необязательны.

Тесты ядра: `node --test tests/core.test.js`. Для интеграционных тестов нужен Playwright и Chromium; см. `tests/integration.mjs`. Для установки расширения запускать тесты или `npm install` не требуется.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Нет плавающей кнопки | Правильная папка без двойного вложения, расширение включено, страница обновлена |
| Ошибка JSON | Меньше сообщений за раз, больше лимит ответа, другая модель |
| HTTP 401 / 429 | Ключ / баланс или ограничение запросов |
| Ошибка сети у отдельного API | URL, CORS; попробовать текущее API Таверны |
| Запись не видна модели | Вкладка «В контекст», включение памяти, бюджет, отключённая запись, изменённый источник |
| Не удалось подтвердить сохранение | Связь с сервером, права на чат, поддержка штатных `/api/chats/get` или `/api/chats/group/get` |
| Событие понято неверно | Исправить и защитить карточку; уточнить дополнительный промпт |

## Исходники

`core.js` — память и отбор; `api.js` — подключения; `index.js` — интеграция и интерфейс; `style.css` — оформление. Исходники открыты в архиве. Внешних CDN-зависимостей нет.

Идеи обсуждались на примере FactsMemoryTracker, SunnyMemories и Horae; эта реализация написана отдельно и не включает их исходники.
