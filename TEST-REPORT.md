# Проверка 1.0.0-beta.3.3

Дата: 17 сентября 2026.

**16 тестов ядра beta.3.3 — успешно.**

После изменений также выполнены `node --check` для `index.js`, `core.js` и `api.js` — синтаксических ошибок нет.

## Что дополнительно изменилось в beta.3.3

1. Основная инструкция архивариуса и инструкции взрослого режима переведены на компактный английский; вывод памяти жёстко задан на русском.
2. Перед отправкой используется токен-счётчик SillyTavern с fallback на локальную оценку.
3. Добавлена классификация пользовательских ошибок и явное сообщение, когда запрос не отправлялся из-за лимита входа.
4. Для HTTP-ошибок отдельного API выводится короткий ответ провайдера.
5. Добавлена кнопка рекомендуемого английского custom prompt.
6. Добавлен лёгкий декоративный sparkle-pass интерфейса с поддержкой reduced motion.

## Ядро — 16 успешных тестов

1. Скрытая история и нулевой индекс.
2. Ошибочный JSON и источники вне диапазона.
3. Проверка точных цитат и отбрасывание выдуманных.
4. Пропуски обработки после редактирования.
5. Удаление источника / ветвление и сохранение ручных записей.
6. Устойчивые ID после вставки сообщения.
7. Приоритет ручной редакции и повторное редактирование.
8. Хронологический приоритет версии факта и возврат предыдущей при смене текста.
9. Пересканирование прошлого не заменяет последнюю сохранённую сцену.
10. Бюджет контекста и уведомление о невместившемся закреплении.
11. Отключение записи и явный запрос флешбэка.
12. Экспорт/импорт без ключей с сохранением привязки к источникам.
13. Повторная обработка не дублирует активные факты.
14. Проверка URL отдельного API.
15. Новый взрослый режим выключен по умолчанию, а его системные инструкции остаются архивными и ограничены совершеннолетними персонажами.
16. Английский extraction prompt явно требует русскоязычный читаемый результат и JSON-only формат.

## Браузерная интеграция

Файл `tests/integration.mjs` сохранён. Ранее базовый набор браузерных сценариев проходил на предыдущей версии. В текущем окружении beta.3.3 повторный запуск не выполнен: npm-модуль Playwright отсутствует, а системный Chromium блокирует локальный тестовый HTTP-хост политикой окружения. Поэтому новый Story Journal UI, merge/delete и переключатели взрослых сцен нужно финально проверить уже в реальной SillyTavern после установки.

Это ограничение тестового окружения, а не обнаруженная ошибка расширения. Ядро и JavaScript-синтаксис после изменений проверены успешно.
